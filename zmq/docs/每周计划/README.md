## 每周执行模板

每周完成后，建议在对应文件末尾补充个人记录：

```markdown
## 学习记录

- 学习日期：
- 实际投入时间：
- 已完成任务：
- 实验结果：
- 遇到的问题：
- 已验证结论：
- 未解决问题：
- 相关代码或提交：
```

每周至少提交以下成果：

- 一张架构图、数据流图或状态机图；
- 一个只验证单一知识点的最小实验；
- 一份实验结果和结论记录；
- 本周验收问题的书面答案。

总知识点清单统一维护在 [ZeroMQ 深入学习总计划](../ZeroMQ深入学习总计划.md) 的“全局知识点清单”章节，周计划不重复维护第二套清单。
