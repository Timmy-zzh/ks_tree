# 第 1 周：ZeroMQ 基础概念和环境

> 配套学习资料：[第 1 周学习资料：ZeroMQ 基础概念与环境](第01周学习资料-基础概念与环境.md)

## 学习目标

建立 ZeroMQ 的整体认知，能够编译并运行第一个 C++ 示例。

## 理论内容

- ZeroMQ 与传统 TCP socket 的区别；
- ZeroMQ 与 Kafka、RabbitMQ 等消息系统的区别；
- libzmq、cppzmq、ZMTP 的关系；
- Context、Socket、Message、Endpoint、Transport；
- `bind` 与 `connect`；
- `tcp://`、`ipc://`、`inproc://`；
- cppzmq 的 header-only 封装、RAII 和异常处理；
- Context 中 I/O 线程的含义；
- 普通 Socket 的线程归属原则。

## 必须掌握的知识点

- ZeroMQ 是嵌入业务进程的通信库，不是默认独立运行的消息服务器；
- `context_t ctx(1)` 表示 ZeroMQ I/O 线程数量，不是业务线程数量；
- `bind` 创建监听端点，`connect` 发起连接；
- `inproc://` 只适用于同一进程，且连接双方通常需要共享同一个 Context；
- cppzmq 是 C++ 绑定，底层仍然依赖和链接 libzmq；
- Context 可以被多个线程使用，普通 Socket 不应由多个线程同时使用。
