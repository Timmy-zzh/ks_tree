# 第 2 周：REQ/REP 和当前基线代码

## 学习目标

完整理解当前 `service_rep.cpp` 和 `client_req.cpp` 的行为，掌握 REQ/REP 状态机。

## 理论内容

- REQ/REP 的同步请求-应答模式；
- `recv -> send -> recv -> send` 状态机；
- 阻塞接收和阻塞发送；
- `message_t` 的内存和长度语义；
- 空消息、二进制消息和包含 `\0` 的消息；
- Socket 和 Context 的生命周期；
- 客户端连接、服务端监听和连接建立不是同一事件。

## 必须掌握的知识点

- REP 不能连续接收两个请求后再响应；
- REQ 不能连续发送两个请求后再接收响应；
- `recv()` 等待的是 ZeroMQ Socket 是否有可交付消息，不是简单读取 TCP 字节流；
- 消息帧由 ZeroMQ/ZMTP 维护，TCP 本身只有字节流；
- `send()` 返回成功不代表对端业务已经完成；
- 客户端断开不一定使服务端永久退出，服务端可能继续等待其他客户端。
