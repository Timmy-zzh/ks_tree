# 第 3 周：消息帧、多段消息和序列化

## 学习目标

理解 ZeroMQ 消息边界、multipart 以及应用层数据协议。

## 理论内容

- 单帧消息；
- multipart message；
- `ZMQ_SNDMORE` / `zmq::send_flags::sndmore`；
- `ZMQ_RCVMORE`；
- 空 frame；
- identity frame；
- 主题 frame；
- 二进制数据；
- JSON、MessagePack、Protobuf、FlatBuffers；
- 协议版本和向后兼容；
- 字节序、长度校验和字段校验。

## 必须掌握的知识点

- TCP 不提供消息边界，ZeroMQ/ZMTP 负责恢复消息和 frame 边界；
- multipart 的多个 frame 属于一次逻辑消息，但不等于业务事务；
- 接收 multipart 时必须接收完整，否则可能破坏后续处理；
- ZeroMQ 消息不是 C 字符串，不保证以 `\0` 结尾；
- `message_t` 可以承载任意字节，不应默认当成 UTF-8 文本；
- 序列化格式属于业务协议，需要版本、校验和错误处理。

## 推荐协议练习

```text
frame 1: version
frame 2: request_id
frame 3: operation
frame 4: payload
```

例如：

```text
v1
request-000001
get_user
{"user_id":1001}
```
