# 第 5 周：线程、进程和内部通信

## 学习目标

掌握 Context、Socket、业务线程、I/O 线程和进程之间的边界。

## 理论内容

- Socket 的线程归属；
- Context 的线程共享；
- I/O 线程职责；
- 应用业务线程职责；
- `inproc://` 线程通信；
- `ipc://` 同机进程通信；
- `tcp://` 跨主机或跨进程通信；
- fork 后重新创建 Context 和 Socket；
- 不在多个线程之间直接共享普通 Socket。

## 推荐架构

```text
主线程 ROUTER
      |
      | inproc://backend
      v
内部 DEALER
      |
      +--> worker 1
      +--> worker 2
      +--> worker 3
```

## 实践任务

1. 实现 ROUTER 前端；
2. 使用 `inproc://` 连接 worker；
3. 每个 worker 创建并使用自己的 Socket；
4. 一个 worker 故意执行慢任务；
5. 关闭一个 worker，观察消息和连接行为；
6. 对比错误共享 Socket 和正确 worker 架构。

## 本周输出

- 线程模型图；
- 进程边界图；
- worker 生命周期说明；
- Socket 归属表。

## 本周验收

能够说明：

```text
Context 可以共享；
普通 Socket 应归属单一线程；
跨线程应通过 inproc 或其他线程安全队列通信；
跨进程不能直接共享 Socket；
fork 后不应继续复用 fork 前创建的 Context 和 Socket。
```
