# 第 6 周：队列、高水位、阻塞和背压

## 学习目标

理解 ZeroMQ 队列和背压语义，能够解释阻塞、丢弃和 `EAGAIN`。

## 理论内容

- `ZMQ_SNDHWM`；
- `ZMQ_RCVHWM`；
- `ZMQ_SNDTIMEO`；
- `ZMQ_RCVTIMEO`；
- `ZMQ_DONTWAIT`；
- `EAGAIN`；
- `ZMQ_LINGER`；
- `ZMQ_MAXMSGSIZE`；
- `ZMQ_IMMEDIATE`；
- 本地队列、Pipe、Session 队列和 TCP 缓冲区；
- 快生产者、慢消费者和内存增长。

## 必须掌握的知识点

- HWM 通常按消息数量计算，不等于字节容量；
- HWM 不是整个系统的严格全局容量承诺；
- 一个超大消息可能占用大量内存；
- 选项通常应在 `bind` 或 `connect` 前设置；
- 不同 Socket 类型在背压和丢弃方面表现不同；
- 非阻塞发送失败时可能返回 `EAGAIN`；
- `send()` 成功只说明消息被本地 ZeroMQ 接受。

## 实践任务

1. 设置很小的发送和接收 HWM；
2. 快速发送大量消息；
3. 让消费者延迟读取；
4. 对比阻塞和 `dontwait`；
5. 记录 `EAGAIN` 次数；
6. 测试 `SNDTIMEO` 和 `RCVTIMEO`；
7. 测试 `LINGER` 对关闭时间和消息丢失的影响；
8. 测试超大消息和 `MAXMSGSIZE`。

## 建议记录指标

```text
发送消息数
接收消息数
丢失消息数
EAGAIN 次数
阻塞时长
平均消息大小
最大消息大小
进程内存
关闭耗时
```
