# 第 7 周：连接生命周期、重连和心跳

## 学习目标

理解连接建立、断开、重连和心跳，不把自动重连误认为业务消息恢复。

## 理论内容

- `ZMQ_RECONNECT_IVL`；
- `ZMQ_RECONNECT_IVL_MAX`；
- `ZMQ_HANDSHAKE_IVL`；
- `ZMQ_HEARTBEAT_IVL`；
- `ZMQ_HEARTBEAT_TIMEOUT`；
- bind 失败与 connect 失败；
- 服务端先启动和客户端先启动；
- 对端重启；
- TCP RST、网络断开和连接超时；
- 重连期间本地队列的行为。

## 实践任务

依次完成：

1. 服务端先启动，客户端后启动；
2. 客户端先启动，服务端后启动；
3. 服务端运行中突然退出；
4. 客户端运行中突然退出；
5. 运行期间阻断网络；
6. 重新启动服务端，观察客户端恢复；
7. 设置心跳和重连间隔；
8. 记录连接事件和请求结果。

## 本周必须回答

- 客户端连接失败时是否会立即报错？
- 服务端重启后 Socket 是否自动恢复？
- 重连期间发送的消息是否一定保留？
- 心跳检测的是连接存活还是业务可用？
- 如何避免重连风暴？

## 本周输出

- 连接状态机图；
- 断线重连时间线；
- 重连参数说明；
- 连接故障排查清单。
