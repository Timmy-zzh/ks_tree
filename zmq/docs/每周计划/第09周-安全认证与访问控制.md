# 第 9 周：安全、认证和访问控制

## 学习目标

能够把一个明文 TCP 示例改造成具有身份认证和加密能力的服务。

## 理论内容

- 默认 NULL security；
- 明文 TCP 的风险；
- CURVE 认证和加密；
- ZAP；
- 服务端和客户端密钥；
- 客户端身份；
- 访问控制；
- 密钥保存和轮换；
- 防火墙和网络隔离；
- 日志脱敏；
- 最大消息大小和速率限制。

## 实践任务

1. 运行明文 TCP 服务；
2. 配置 CURVE 服务端；
3. 配置 CURVE 客户端；
4. 使用错误密钥连接；
5. 测试未授权客户端；
6. 记录握手失败和认证失败；
7. 将 `tcp://*:5555` 改为明确的监听地址进行对比；
8. 制定密钥配置文件的权限要求。

## 本周输出

- 安全威胁模型；
- CURVE 密钥和配置说明；
- 认证失败测试记录；
- 生产网络暴露检查表。

## 本周验收

看到以下代码时，应主动分析风险：

```cpp
sock.bind("tcp://*:5555");
```

需要检查：

- 是否真的要监听所有网卡；
- 是否有防火墙限制；
- 是否需要加密和身份认证；
- 是否限制消息大小和连接速率；
- 是否会把敏感请求写入日志。
