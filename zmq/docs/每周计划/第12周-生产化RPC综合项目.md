# 第 12 周：生产化 RPC 综合项目

## 学习目标

完成一个具备基本生产特征的小型 RPC 系统，并用故障实验验证设计。

## 推荐架构

```text
客户端
  |
  | REQ 或 DEALER
  v
RPC Gateway
  |
  | ROUTER / DEALER + inproc
  v
Worker Pool
  |
  v
业务处理模块
```

## 项目必须包含

- request ID；
- 多帧协议；
- JSON、MessagePack 或 Protobuf；
- 参数校验；
- 错误码和响应状态；
- 接收和发送超时；
- 有限重试和指数退避；
- 幂等和重复请求去重；
- HWM 和最大消息大小；
- 优雅退出；
- CURVE 认证；
- socket monitor；
- 结构化日志；
- 指标统计；
- 单元测试；
- 压力测试；
- 断网恢复测试；
- 服务端崩溃恢复测试；
- 重复请求测试。

## 项目验收问题

必须能够回答并通过实验验证：

1. 服务端重启后客户端如何恢复？
2. 请求处理成功但响应丢失时如何处理？
3. 一个 worker 崩溃后任务如何处理？
4. HWM 满时如何限流或失败？
5. 消息过大时如何拒绝？
6. 客户端重复请求时如何避免重复业务？
7. 认证失败如何记录和告警？
8. 如何优雅停止并控制 LINGER？
9. 如何区分“进程健康”“连接健康”和“业务健康”？
10. 如何通过指标发现排队、重连和延迟问题？
